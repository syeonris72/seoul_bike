# 서울 따릉이 대여 수요 예측 프로젝트

서울시 공공자전거(따릉이) 대여 수요를 예측하는 팀 프로젝트입니다.
예측 모델을 바탕으로 재배치 운영을 지원하는 웹 서비스까지 개발하는 것이 목표입니다.

### 팀 구성

* 팀원 5명
* 1명은 EDA 전담 및 랜딩 페이지 개발
* 나머지 인원은 세로 분할(역할/페이지별 풀스택) 방식으로 웹 개발 진행

### 기술 스택

* 분석/모델링: Python, scikit-learn, Optuna, MLflow
* 저장소: Supabase Storage (S3 호환)
* 프론트엔드: React
* 백엔드: FastAPI

### 사용자 역할

* 사용자: 자전거 대여/반납
* 기사: 자치구별 배치 및 재배치 수행
* 관리자(서울): 자치구 간 재배치 명령
* 관리자(자치구): 자치구 내 재배치 명령

관리자는 예측/운영 대시보드, 지도 기반 예측 시각화, 기사 위치 및 명령 이력 확인 기능을 사용할 수 있습니다.
